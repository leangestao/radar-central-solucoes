# Radar da Central de Soluções

Dados da página https://leangestao.com.br/cs — monitoramento da Central de Soluções Domínio feito pela LEAN Performance.

- `dados.json` — atualizado automaticamente após cada checagem (segunda, quarta e sábado) e no resumo semanal (segunda).
- `index.html` — cópia da página publicada em `public_html/cs/` na hospedagem. Ela lê o `dados.json` deste repositório; só precisa ser reenviada se o layout mudar.
